 Smoking Health Risk Analysis Dashboard:

An interactive Power BI dashboard designed to analyze smoking-related health risks and explore the relationship between smoking behavior, demographics, and organ health.
This project demonstrates the use of **Data Analytics, Power BI, Data Modeling, DAX, and Data Visualization** to transform healthcare-related datasets into meaningful and interactive insights.

Project Overview
Smoking is one of the major lifestyle factors associated with several long-term health risks. This dashboard provides an interactive way to explore how smoking patterns vary across different demographic and health-related factors.

The dashboard allows users to analyze:

* Smoking status
* Smoking duration
* Daily cigarette consumption
* Age-wise smoking patterns
* Gender-wise smoking patterns
* Cholesterol levels
* Hypertension
* BMI
* Organ health conditions
* Healthy vs. damaged organs

The goal is to make complex health-related data easier to understand through interactive visualizations.


 Objectives

The main objectives of this project are:

* Analyze smoking patterns across different age groups.
* Compare smoking behavior between genders.
* Understand the relationship between smoking and health conditions.
* Analyze organ health based on smoking-related factors.
* Identify important health-risk patterns using visual analytics.
* Build an interactive and user-friendly Power BI dashboard.

**`condition.csv`**
Contains health-condition information used in the dashboard.

**`Image Dataset.csv`**
Contains image-related data used to support the dashboard visualization.

**`smoking health risk analysis.pbix`**
The main Microsoft Power BI dashboard file.


 Dashboard Features

 1. Smoking Analysis
The dashboard provides insights into different smoking categories and allows users to explore smoking-related patterns.
 2. Demographic Analysis
Users can analyze smoking behavior across:
* Age groups
* Gender
* Smoking status
 3. Health Risk Analysis
The dashboard explores health indicators such as:
* Cholesterol
* Hypertension
* BMI
* Smoking duration
* Daily cigarette consumption
 4. Organ Health Analysis
The dashboard provides a visual comparison of **healthy and damaged organs**, helping users explore the potential relationship between smoking behavior and organ health.
 5. Interactive Filtering
Power BI slicers and filters allow users to dynamically explore the data and focus on specific demographic or health categories.
