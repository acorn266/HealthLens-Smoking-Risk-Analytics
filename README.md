# HealthLens — Smoking Risk Analytics

HealthLens is an interactive **Power BI dashboard** that analyzes smoking-related health risks and identifies patterns across demographics, smoking habits, health conditions, and affected organs.

## 📊 Features

* Analyze smoking patterns and their relationship with health conditions
* Explore health risks across age and gender groups
* Compare smoking duration and cigarette consumption
* Analyze affected organs and health conditions
* Interactive filters and visualizations for deeper insights
* KPI-driven dashboard for quick health-risk analysis

## 🛠️ Tech Stack

* **Power BI**
* **Power Query**
* **DAX**
* **Data Modeling**
* **CSV / Data Analysis**

## 📁 Dataset

The project uses structured healthcare datasets containing information related to:

* Smoking habits
* Demographics
* Health conditions
* Organ health
* Health indicators

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/acorn266/HealthLens-Smoking-Risk-Analytics.git
```

2. Open `HealthLens.pbix` using **Microsoft Power BI Desktop**.
3. Refresh the data sources if required.
4. Explore the interactive dashboard.

## 🎯 Objective

The goal of HealthLens is to transform health and smoking-related data into **clear, interactive visual insights** that make it easier to identify patterns and understand potential health risks associated with smoking.
